### P1.2 细化（2026-06-16 调研结论）

**已就绪**：electron-builder build 配置完整（appId、generic publish、nsis、files、`extraResources` 期望后端产物在 `build/dist/ipmaster-cowork`→`backend`、`packaging/default_data`→`default_data`）；electron/main.js 启停/更新/遥测/legacy 迁移齐全；`electron/assets/icon.ico` 在。

**缺失/需补**：

| 子项 | 说明 |
|---|---|
| a. **桌面入口 `_run.py`**（新仓无） | PyInstaller 入口。须：读 `IPMASTER_COWORK_ENV_FILE`/`IPMASTER_COWORK_BACKEND_PORT`(=15926)；冻结模式 stdout/stderr 修复；**把 `frontend-desktop/dist` 挂成 SPA**（index.html `no-store` 防缓存）；启动 uvicorn。参考旧仓 `D:\20_code\miniAgentsDemo\_run.py` |
| b. **后端不挂前端** | 新后端 `serve` 只出 REST/SSE，无 StaticFiles。electron `loadURL(:15926)` 拿不到 UI → 由 (a) 的 SPA mount 解决 |
| c. **端口契约不一致** | electron 传 `IPMASTER_COWORK_BACKEND_PORT=15926`，但 cli `serve` 只读 `--port`(默认 8000) 且不读该 env → 由 (a) `_run.py` 直接读该 env 解决（cli serve 保持 8000 供手动用） |
| d. **env 前缀不一致**（需决策） | electron / `.env` 用 `IPMASTER_COWORK_*`，后端读 `NLC_*`。三种方案：① `_run.py` 内做 `IPMASTER_COWORK_*`→`NLC_*` 翻译（改动最小、桌面胶水集中一处，**推荐**）；② 把 electron+.env.example+legacy 迁移全改 `NLC_*`（最干净、churn 大）；③ 后端 config 双前缀兼容 |
| e. **PyInstaller spec** | 入口 `_run.py`；datas 嵌 `frontend-desktop/dist`→`frontend_dist`；hiddenimports（uvicorn.*/anthropic/openai/mcp/httpx/psutil/python_multipart 等）；excludes（tkinter/numpy/...）；exe 名 `ipmaster-cowork`、`console=False`。参考旧仓 `packaging/ipmaster-cowork-desktop.spec`（去掉 cairosvg/GTK3，除非需要 SVG 图标） |
| f. **编排脚本 `build_electron.ps1`** | frontend-desktop build → PyInstaller → 复制 `resources/`+`.env.example` 到 dist → electron-builder。参考旧仓同名脚本（含 winCodeSign 缓存修复、全量重打纪律） |
| g. **`packaging/default_data/`** | electron-builder `extraResources` 指向它（llm_configs/mcp_configs 种子）。缺则首次 seeding 空跑 |

## P2 — 日志 / 上报闭环

**目标**：把「后端产事件 → 落 spool → Electron drain → 上传 :8077」与「用户主动上报会话+日志」两条链路打通。
当前 electron reporter 已在，但后端不产 spool、无 env-heal，**整条链路是断的**。

| # | 任务 | 端 | 验收标准 |
|---|------|----|---------|
| 2.1 | 后端遥测 `emit`/spool | 后端 | 新增 `observability/events.py`：LLM/MCP/skill 失败追加写 `data_dir/telemetry-spool.jsonl`（一行一 JSON，open-append-close，异常静默）。单测：失败路径产出 spool 行 |
| 2.2 | `env-heal` | electron | `electron/lib/env-heal.js`：`.env` 缺 DATA_DIR/LOG_DIR 时自动补，保证 spool 落 AppData。验收：缺行场景启动后 spool 落点正确 |
| 2.3 | 日志打包上报 | electron | `log-bundler.js`/`zip.js`/`log-uploader.js`：crash/requested 两 mode，multipart POST `/logs` 到 :8077。验收：手动触发能生成 zip 并上传成功 |
| 2.4 | 会话上报闭环 | 两端 | 后端 `GET /sessions/{id}/export`（返回文件清单，**排除 llm_configs/mcp_configs 等含密配置**）+ 前端 report-session IPC + 上报按钮。验收：点「上报此会话」→ 打 zip → 上传成功，且 zip 内无密钥 |
